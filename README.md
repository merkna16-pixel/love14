# ❤️ Love App - Якуб + Соня

Приложение для пары для управления задачами, внутренней валютой и памятными моментами.

## Возможности

- 🔐 **Аутентификация** - вход для обоих пользователей
- ✅ **Задания** - ежедневные задачи с подтверждением
- 🪙 **Система коинов** - награды за выполненные задания
- 🛍️ **Магазин** - приватные покупки с датами
- 📜 **История** - лента всех событий
- 🔥 **Серия** - отслеживание дней вместе

## Технологический стек

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Node.js + Express
- **База данных**: Supabase (PostgreSQL)
- **CORS поддержка**: Полная кросс-доменная поддержка

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/merkna16-pixel/love14.git
cd love14
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Настроить переменные окружения

Создать файл `.env` в корне проекта:
```
SUPABASE_URL=https://ваш-проект.supabase.co
SUPABASE_KEY=ваш_anon_key_здесь
PORT=3000
```

**Как получить ключи:**
1. Перейти на [supabase.com](https://supabase.com)
2. Открыть свой проект
3. Settings → API
4. Скопировать **Project URL** и **anon public key**

### 4. Запустить сервер
```bash
npm start
```

Приложение будет доступно на `http://localhost:3000`

## API Endpoints

- `POST /api/login` - вход пользователя
- `GET /api/data` - получить все данные
- `POST /api/task/do` - выполнить задание
- `POST /api/task/confirm` - подтвердить задание
- `POST /api/shop/buy` - купить товар из магазина

## Для разработки
